# Exploración Inteligente para la Ciencia de Datos (MCDI503)

Proyecto académico UNAB: análisis exploratorio reproducible de los factores asociados a la supervivencia en Titanic.

## Estructura
- `datos/`: dataset original (sin modificar).
- `F1/`: planificación, notebook inicial e informe de la Fase 1.
- `F2/`, `F3/`, `F4/`: avances posteriores.

## Inicio
1. Instalar Python y las dependencias: `pip install -r requirements.txt`.
2. Guardar el CSV recibido en `datos/titanic.csv`.
3. Abrir `F1/F1_Sumativa_EDA_Titanic.ipynb` en VS Code o Jupyter.
4. Ejecutar todas las celdas desde cero y revisar las interpretaciones.

**Nota:** el notebook inicial es una plantilla de trabajo; no constituye aún una entrega ejecutada. No publicar datos personales ni credenciales en este repositorio público.
